User Guide

Welcome to the official documentation for Kani, your Discord automation bot for YouTube livestreams and personal reminders.

Getting Started

To use Kani, your server administrator must first invite the bot and grant it the Manage Events permission to create scheduled events automatically.

Commands

  • /addchannel <channel_id> - Add a YouTube channel ID to monitor for upcoming streams.
  • /removechannel <channel_id> - Remove a YouTube channel from the monitor list.
  • /setping <youtube_channel_id> <ping_channel> <ping_role> - Set the Discord text channel and role to ping when a stream goes live.
  • /refresh - Manually check monitored YouTube channels for new streams and create events.
  • /test <youtube_channel_id> - Test the live ping message to ensure permissions and settings are correct.
  • /remind <duration> <message> - Set a persistent personal reminder (e.g., 15m, 2h, 1d).

Automated Features

Kani checks YouTube for upcoming streams every 2 hours and creates Discord Scheduled Events. It also checks for live statuses every 5 minutes to send alerts and updates the original message when the stream ends.
