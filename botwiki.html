mizuBot Documentation

mizuBot is a straightforward moderation utility designed to help server administrators efficiently manage user timeouts with built-in role hierarchy safeguards.

Slash Commands

The bot features a primary slash command restricted to users with the Moderate Members permission.

/timeout

Applies a temporary timeout to a specified user in the guild.

  • member: The user you want to timeout.
  • minutes: Duration of the timeout in minutes.
  • reason: An optional text reason detailing why the user is being timed out.
Security & Role Hierarchy

The bot checks both the bot's own role position and the command executor's role hierarchy to prevent unauthorized timeouts or attempts to timeout server owners and higher-ranked members.

Privacy Policy

mizuBot respects your server's privacy and minimizes data collection strictly to what is necessary for functional moderation.

Data Collection

To execute moderation commands and maintain security checks, the bot processes:

  • User IDs & Member Roles: Processed dynamically in memory to verify hierarchy permissions.
  • Server IDs: Used to track command execution context.
  • Audit Details: Timestamps and reasons provided during a timeout command execution.

Data Retention

The bot does not permanently log or store personal message contents. All transient interaction data is handled securely and cleared in accordance with standard Discord API lifecycles.
